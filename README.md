# Бесплатный Telegram-бот по обществознанию

В этой версии:
- 300 заранее прописанных вопросов;
- готовые правильные ответы;
- готовые объяснения;
- тренировка по 5 вопросов и тест по 10 вопросов;
- раздел «Мои ошибки»;
- статистика;
- серия дней (streak);
- база SQLite, которая создаётся автоматически;
- никаких платных AI API.

## 1. Создай бота в Telegram

Открой @BotFather.

1. Отправь `/newbot`
2. Придумай имя
3. Придумай username, который заканчивается на `bot`
4. Скопируй токен

## 2. Установи Python

Нужен Python 3.10+.

## 3. Установи зависимости

В папке проекта:

```bash
pip install -r requirements.txt
```

## 4. Создай файл .env

Скопируй `.env.example` в `.env`.

Внутри должно быть:

```env
BOT_TOKEN=твой_токен_от_BotFather
```

## 5. Запусти

```bash
python bot.py
```

Пока программа работает на компьютере, бот работает.

## Как добавить свои вопросы

Открой `questions.py` и добавь новый блок:

```python
{
    "id": 26,
    "topic": "Экономика",
    "question": "Текст вопроса",
    "options": ["Ответ 1", "Ответ 2", "Ответ 3", "Ответ 4"],
    "correct": 1,
    "explanation": "Почему этот ответ правильный."
}
```

`correct` начинается с нуля:
- `0` = первый вариант;
- `1` = второй;
- `2` = третий;
- `3` = четвёртый.

## Стоимость

Сам код и запуск на своём компьютере — бесплатно.

Если нужен бот 24/7, понадобится либо:
- держать свой компьютер включённым;
- либо использовать бесплатный тариф хостинга, если подходящий доступен;
- либо позже взять дешёвый VPS.

Для первой проверки идеи платить ничего не нужно.


## Банк вопросов

В `questions.py` находится 300 полностью локальных тренировочных вопросов: по 60 на каждый из пяти блоков — «Человек и общество», «Экономика», «Социальные отношения», «Политика», «Право».

Все варианты, правильные ответы и объяснения уже записаны. Во время работы бот ничего не генерирует через ИИ и не обращается к платным API.

Это авторские тренировочные вопросы, а не официальный банк ФИПИ.


## Встроенная реклама

В проект добавлена картинка `assets/ad.jpg`.

Рекламный блок показывается:
- перед вопросом №1;
- затем перед вопросом №6;
- затем перед №11, №16 и далее через каждые 5 вопросов;
- после последнего вопроса реклама специально не показывается.

Под рекламой есть кнопка на `https://egetraining.com`.

Чтобы поменять частоту, измени в `bot.py`:

```python
AD_EVERY = 5
```

Чтобы заменить рекламу, просто замени файл `assets/ad.jpg`.
